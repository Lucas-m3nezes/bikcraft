## Projeto

Desenvolvimento do site **Bikcraft**, uma loja fictícia de bicicletas elétricas feitas sob medida, construído como projeto prático do curso de **HTML e CSS para Iniciantes** da [Origamid](https://www.origamid.com). O projeto é um site multi-páginas com catálogo de produtos, planos de seguro e formulário de orçamento.

> 🌐 [Acesse o site](https://lucas-m3nezes.github.io/bikcraft/) &nbsp;|&nbsp; 📁 [Acesse o repositório](https://github.com/Lucas-m3nezes/bikcraft)

## Páginas

| Página | Descrição |
|---|---|
| Home | Apresentação, destaques dos produtos e planos de seguro |
| Bicicletas | Catálogo com os três modelos disponíveis |
| Seguros | Planos Prata e Ouro com detalhamento de coberturas |
| Contato | Formulário de contato |
| Orçamento | Formulário de solicitação de orçamento |
| Termos | Termos e condições de uso |

## O que aprendi

- **Flexbox** — organização e alinhamento de elementos em uma dimensão
- **CSS Grid** — construção de layouts bidimensionais
- **Responsividade** — adaptação do layout para diferentes tamanhos de tela
- **Semântica HTML** — uso correto de tags como `<header>`, `<main>`, `<section>`, `<footer>` e outras
- **Site multi-páginas** — organização de um projeto com múltiplos arquivos HTML interligados
